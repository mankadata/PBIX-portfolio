Data

FAOSTAT QCL (production) and TCL (trade) domains, item code 656 — coffee, green, pulled live through the FAOSTAT REST API with token authentication.

Modelling

Parameterised Power Query functions, a dedicated _Measures table, and DAX written in the DAX query view with inline comments.

Visuals

Custom HTML and SVG visuals generated inside DAX measures — the waffle grid, the KPI row and the ranking cards are all hand-built.

A bug worth mentioning

FAOSTAT returns aggregate rows (World, Africa, European Union (27)) alongside countries. Left in, every total runs 4–7× too high. They are filtered out in Power Query.

The report takes its starting point from Gus Bavia's MIT-licensed The World of Peaches, winner of the 2026 Power BI World Championship. The subject, the data pipeline, the measures, the layout and the visual design here are my own.
